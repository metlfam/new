# START

**Не нужно делать всё. Нужно просто начать.**

Русскоязычное адаптивное приложение против прокрастинации. React 19, TypeScript, Vite, Tailwind CSS 4, Lucide. Без сервера, регистрации, аналитики и API-ключей. Исходное техническое задание: [docs/SPEC.md](docs/SPEC.md).

## Локальный запуск

Нужен Node.js 22.12+ (проверено на Node.js 24).

```bash
npm install
npm run dev
```

Для воспроизводимой установки из lockfile используйте `npm ci`. Откройте адрес, напечатанный Vite в терминале. Для работы с данными используйте один и тот же origin: адреса и порты имеют отдельные localStorage.

```bash
npm run build      # проверка TypeScript и production-сборка в dist/
npm run preview    # локальная проверка собранного приложения
npm test           # модульные проверки
npm run test:e2e   # сценарии в реальном Chromium
npm run format:check
```

Для браузерных тестов используется `/usr/bin/chromium`, если он установлен. Иначе установите браузер командой `npx playwright install chromium` или задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Самому приложению Chromium как зависимость не нужен. Браузерные тесты автоматически запускают Vite; production-сборка подходит для статического хостинга. Публикация автоматически не выполняется.

## Что реализовано

- Главная: создание задач до 200 символов, быстрые примеры, реальные показатели дня, продолжение последней активной задачи.
- Локальный генератор: семь категорий и наборы из пяти шагов; специальные планы для экзаменов и курсовых. Никаких запросов к нейросети.
- Задачи: поиск, фильтры, изменение названия, добавление, редактирование, удаление и перестановка шагов. Статус вычисляется по шагам; снятие отметки открывает задачу снова.
- Фокус: 2, 5, 10, 15 и 25 минут, пауза, клавиша Space, подтверждение досрочного завершения, отзыв о результате, переход к следующему шагу.
- Таймер: расчёт по абсолютному времени окончания, восстановление после перезагрузки и закрытия вкладки. Пауза не засчитывается в фокус. Истёкшая сессия сохраняется один раз с фактическим временем окончания.
- Прогресс: минуты, полные сессии, шаги и задачи, недельный график, текущая и лучшая серия по локальным календарным дням. Досрочные сессии сохраняют минуты, но не увеличивают серию.
- Настройки: светлая/тёмная/системная тема, звук, стандартная длительность, экспорт/импорт JSON, подтверждённый сброс только данных START.
- Адаптивная навигация, нативные модальные диалоги с удержанием и восстановлением фокуса, видимый клавиатурный фокус, reduced motion.
- Favicon, метаданные и web app manifest.

## Данные и надёжность

Единственный ключ приложения: `start-app-data-v1`. Формат версии 1 проверяется Zod при чтении и импорте. Экспорт содержит задачи, шаги, сессии, активный таймер и настройки. Импорт ограничен 10 МБ, выполняется только после проверки и подтверждения замены. Перед переносом данных лучше закончить текущую сессию.

Повреждённые данные не перезаписываются молча: приложение предлагает скачать исходный JSON и работает в памяти до явного сброса/восстановления. При запрете или переполнении localStorage показывается предупреждение; текущие данные можно экспортировать. Очистка браузера удаляет локальные данные — делайте резервные копии.

Изменения между вкладками передаются через `storage`. В современных браузерах Web Locks сериализует запись с повторным чтением актуальных данных; идентификатор сессии защищает завершение от повторного начисления. Если Web Locks недоступен (например, при обычном HTTP вне localhost), остаётся синхронизация `storage`, но полная атомарность одновременных изменений не гарантируется. Для нескольких вкладок используйте localhost или HTTPS.

При обнаружении скачка системного времени во время работы таймер консервативно ставится на паузу. Изменения часов, сделанные при полностью закрытом приложении, невозможно достоверно отличить от прошедшего времени без внешнего источника времени.

## Структура

- `src/pages/` — шесть экранов, включая детали задачи.
- `src/components/` — диалоги, общие элементы и карточка задачи.
- `src/lib/taskGenerator.ts` — независимый локальный генератор и состояние задачи; здесь можно подключить другой генератор во второй версии.
- `src/lib/timer.ts` — чистые функции таймера.
- `src/hooks/useFocusTimer.ts` — обновление времени, восстановление и завершение.
- `src/lib/storage.ts`, `validation.ts` — хранение, синхронизация и проверка формата.
- `src/lib/statistics.ts` — календарные даты и статистика.
- `tests/` — модульные и браузерные сценарии.

## Границы MVP и следующая версия

Генератор использует шаблоны: необычную задачу стоит уточнить вручную. Данные не синхронизируются между устройствами. Manifest подготовлен, но service worker отсутствует: установка и гарантированный запуск без сети не реализованы. Звук зависит от политики браузера и не гарантируется при закрытой вкладке. Число выполненных шагов/задач относится к существующим задачам; история времени и сессий сохраняется после удаления задачи.

Для второй версии: пользовательские шаблоны и более точное распознавание задач; полноценный offline-режим; история изменений с отменой удаления; расширенная проверка доступности и тестирование в Safari/Firefox; при необходимости — сменный AI-генератор с явным согласием на отправку текста.
